Dé du destin

## À propos

Le but est de créer un dé qui tirerait un nombre au hasard dans le domaine choisi.
L'idée est de se baser sur le True RNG (vrai aléatoire) pour tirer au sort. 
Pour ce faire, quoi de mieux que d'utiliser le chaos réel et l'entropie pour s'assurer 
du bon fonctionnement du dé. En effet, les fonctions comme random() sont basées sur 
des algorithmes déterministes et une logique pseudo-aléatoire. Le projet permet de contrer 
la prévisibilité du dé en utilisant des phénomènes naturels.
